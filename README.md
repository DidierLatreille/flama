# 🍔 FLAMA - POC

Un *Proof of Concept* (POC) diseñado y desarrollado para explorar la presencia digital de Flama. Este proyecto se centra en ofrecer una experiencia de usuario (UX) fluida, un diseño atractivo para la presentación de los productos y una interfaz completamente responsiva.

## ✨ Características Principales

*   **Menú Digital:** Presentación clara de las hamburguesas, acompañamientos y bebidas.
*   **Diseño Responsivo:** Experiencia optimizada para dispositivos móviles y de escritorio.
*   **Sección de Contacto:** Integración de horarios de atención, ubicación y enlaces a redes sociales.
*   **Rendimiento Optimizado:** Carga rápida de imágenes y transiciones fluidas.
